# Product Roadmap

This roadmap represents the planned evolution of Poyino.

The roadmap is intended as a strategic direction rather than a strict implementation schedule. Priorities may change based on user feedback and business needs.

# Guiding Principles

When prioritizing new features, always follow these rules:

1. Solve real hiring problems.
2. Keep the product simple.
3. AI should reduce manual work.
4. User feedback has higher priority than assumptions.
5. Build for long-term scalability.
