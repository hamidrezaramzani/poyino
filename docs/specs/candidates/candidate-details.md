# Overview

The Candidate Profile is the primary workspace for recruiters.

It provides a complete overview of a candidate, including:

- Personal information
- Resume
- AI analysis
- Skills
- Experience
- Education
- Hiring status
- Recruiter notes
- Activity timeline

Recruiters should not need to leave this page during the review process.

---

# Business Goal

Enable recruiters to evaluate candidates quickly by combining structured candidate data, resume content, AI insights and recruitment actions in a single page.

# User Story

As a recruiter,

I want to review a candidate in one place,

So that I can make hiring decisions without switching between multiple screens.

# Business Rules

- Recruiters only access candidates within their organization.
- Recruiter notes are never exposed publicly.
- AI analysis is read-only.
- Resume files cannot be modified after submission.
- Every status change is recorded in the activity timeline.
