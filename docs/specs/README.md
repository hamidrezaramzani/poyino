# Specifications

Feature specifications should be created in this directory before implementation begins.

Recommended structure:

```text
docs/specs/
└── feature-name/
    ├── overview.md
    ├── user-flow.md
    ├── ui.md
    ├── api.md
    ├── database.md
    └── acceptance-criteria.md
```

Every specification should explain:

- Business goal
- Primary user flow
- Inputs and validation rules
- API and data requirements
- Edge cases
- Acceptance criteria
