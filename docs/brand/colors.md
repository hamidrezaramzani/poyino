# Color Philosophy

Poyino's color system is designed to communicate:

- Trust
- Intelligence
- Clarity
- Professionalism
- Innovation

Blue is the primary brand color because it represents confidence, reliability, and technology, while darker shades create a premium SaaS appearance.

# Color Usage Guidelines

## Primary

Used for:

- Primary buttons
- Active navigation
- Links
- Selected states
- Focus indicators

---

## Accent

Used for:

- AI features
- Highlights
- Charts
- Important badges

---

## Success

Used for:

- Successful actions
- Completed hiring stages
- Positive status indicators

---

## Warning

Used for:

- Pending actions
- Caution messages

---

## Error

Used for:

- Validation errors
- Failed actions
- Critical alerts

---

# Accessibility

All text and UI elements should meet WCAG AA contrast requirements.

Color should never be the only indicator of status or meaning.

Always pair colors with icons, labels, or supporting text.
