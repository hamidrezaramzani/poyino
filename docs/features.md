# Features

**Version:** 1.0 (MVP)

This document lists all features included in the first public version of Poyino.

---

# Authentication

Manage organization authentication and account security.

## Features

- Organization Registration
- Login
- Forgot Password
- Reset Password

---

# Dashboard

Provide a quick overview of the recruitment process.

## Features

- Recruitment Statistics
- Recent Job Posts
- Recent Applications
- Quick Navigation

---

Manage organization information and branding.

## General

- Organization Information
- Contact Information
- Timezone
- Language

## Branding

- Organization Logo
- Brand Colors

## Notifications

- Email Notifications
- In-App Notifications

## Security

- Change Password

# Out of Scope (Version 1)

The following features are intentionally excluded from the MVP.

- Subscription Plans
- Online Payments
- Team Members
- Roles & Permissions
- Invitations
- Public Job Marketplace
- Career Pages
- Mobile Application
- Public API
- AI Chat
- AI Candidate Comparison
