# Out of Scope

The following features are intentionally excluded from Version 1.0.

- Subscription & Billing
- Team Members
- Multi-role Permissions
- Notifications
- Calendar Integration
- AI Resume Chat
- AI Interview Assistant
- Public Job Marketplace
- Career Pages
- Recruitment CRM
- Mobile Application
- Public API
